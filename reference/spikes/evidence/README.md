# Evidence

One CSV per spike run, exported from `SPIKE_LAB.EVIDENCE.OBSERVATION` using the query at the end of each script.

Naming: `<spike>_<yyyymmdd>[_<n>].csv`, for example `S1_20261006.csv`, `P0_20261006.csv`.

Files are committed unedited. If a run is repeated after a script change, keep both files and note the reason in `docs/spike-log.md`.
